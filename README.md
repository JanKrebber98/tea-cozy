# The Tea Cozy

> This is a project from [Codecademy](https://www.codecademy.com/).

A single-page website for the fictional tea shop "The Tea Cozy", built with plain HTML and CSS according to the provided design spec.

## Structure

- `index.html` – page markup
- `style.css` – styles
- `public/img/` – images
- `public/spec/` – design spec (redline) from Codecademy

## Run

Open `index.html` in a browser.
